\# Projeto de Análise de Vendas - ETL e IA



\## 📋 Descrição do Projeto



Sistema completo de ETL (Extract, Transform, Load) e Análise Inteligente de dados de vendas, com geração automática de relatórios e insights estratégicos.



\## 📁 Estrutura do Projeto



CETL\_Vendas/

├── src/ # Códigos fonte

│ ├── etl\_pipeline.py # Pipeline ETL

│ ├── analise\_inteligente.py # Análise de dados

│ └── ...

├── scripts/ # Scripts de execução

│ └── executar\_etl.bat # Executar ETL

├── logs/ # Logs do sistema

├── reports/ # Relatórios gerados

│ ├── html/ # Relatórios HTML

│ ├── excel/ # Relatórios Excel

│ └── csv/ # CSVs de resumo

├── backup/ # Backups automáticos

├── config/ # Configurações

└── docs/ # Documentação
